# Missão Resiliência — Protótipo 1

Primeira versão funcional do jogo educativo ambiental.

## O que já funciona
- Nome/apelido do jogador
- Escolha de missão
- Tabuleiro com 35 casas
- Dado virtual
- Perguntas de múltipla escolha
- Acerto = avança o valor do dado
- Erro = permanece na mesma casa
- Casas especiais
- Escudo de Resiliência
- Pontuação
- Resultado final
- Títulos por desempenho
- Ranking local salvo no navegador

## Arquivos
- `index.html`
- `style.css`
- `script.js`

## Como testar
Abra `index.html` no navegador.

Para publicar no GitHub Pages, envie os três arquivos para a raiz do repositório e ative:
Settings → Pages → Deploy from a branch → main / root.
